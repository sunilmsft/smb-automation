🛠️ Personal Laptop Setup Guide

Set up everything to work on ALL your projects from your personal machine

Step 1 — Install Core Tools

These are needed for every project. All free.

1️⃣ Visual Studio Code Free

  • Download from code.visualstudio.com
  • Install with default settings

2️⃣ Git Free

  • Download from git-scm.com
  • Accept all defaults during install
  • Then configure your identity:
git config --global user.name "Sunil Venugopal"
git config --global user.email "sunil1308@gmail.com"

3️⃣ GitHub CLI Free

  • Download from cli.github.com
  • After install, authenticate:
gh auth login
# Choose: GitHub.com → HTTPS → Login with browser

4️⃣ Node.js (LTS) Free

Required for: Swoop, FrontDesk AI, Tuck, HomeOps Hub, Kolo, Project Cushion

  • Download LTS from nodejs.org
  • This also installs npm (package manager)
  • Verify after install:
node --version   # Should show v20+ or v22+
npm --version    # Should show 10+

5️⃣ Python 3 Free

Required for: Lunch Menu Notifier

  • Download from python.org
  • ✅ Check "Add Python to PATH" during install
  • Verify: python --version

6️⃣ GitHub Copilot Extension In VS Code

  • Open VS Code → Extensions (Ctrl+Shift+X)
  • Search "GitHub Copilot" → Install
  • Sign in with your GitHub account (sunilmsft)

Step 4 — Per-Project Setup

Each project has different dependencies. Run npm install in each project folder that has a package.json.

📱 Swoop Node.js

cd "OneDrive\GitHub Copilot Fun Projects\swoop"
npm install

Env vars needed in .env:

TWILIO_ACCOUNT_SID=your_sid
TWILIO_AUTH_TOKEN=your_token
TWILIO_PHONE_NUMBER=+1xxxxxxxxxx
OPENAI_API_KEY=sk-...

Run: node server.js

🏪 FrontDesk AI Node.js

cd "OneDrive\GitHub Copilot Fun Projects\frontdesk-ai"
npm install

Env vars needed in .env:

GEMINI_API_KEY=your_gemini_key
ALLOWED_ORIGINS=http://localhost:3000

Run: node server/index.js

👨‍👩‍👧‍👦 Kolo React + Vite

cd "OneDrive\GitHub Copilot Fun Projects\Loopi"
npm install

Env vars needed in .env:

VITE_SUPABASE_URL=https://xxx.supabase.co
VITE_SUPABASE_ANON_KEY=your_anon_key

Run: npm run dev

📌 Tuck React + Express

cd "OneDrive\GitHub Copilot Fun Projects\Tuck"
npm install

Env vars needed in .env:

AZURE_STORAGE_CONNECTION_STRING=your_connection_string
USE_LOCAL_STORAGE=true   # for local dev without Azure

Run: npm run dev

🏠 HomeOps Hub Next.js + Prisma

cd "OneDrive\GitHub Copilot Fun Projects"   # root-level homeops
npm install

Env vars needed in .env:

DATABASE_URL=postgresql://...
NEXTAUTH_SECRET=any_random_string
AUTH_GOOGLE_ID=your_google_client_id
AUTH_GOOGLE_SECRET=your_google_secret

Then run migrations and start:

npx prisma migrate dev
npm run dev

💰 Project Cushion TypeScript CLI

cd "OneDrive\GitHub Copilot Fun Projects\Project Cushion"
npm install

No env vars needed (100% local, zero cloud). Run tests:

npm test

🍽️ Lunch Menu Notifier Python

cd "OneDrive\GitHub Copilot Fun Projects\School Projects\lunch-menu-notifier"
pip install -r requirements.txt

Env vars (set in GitHub Actions secrets, not needed locally unless testing):

PUSHOVER_USER_KEY=your_key
PUSHOVER_API_TOKEN=your_token

📊 SMB Dashboard / Command Center No setup needed

cd "OneDrive\GitHub Copilot Fun Projects\Tim and Sunil building Stuff!"

Pure HTML — just open index.html or projects.html in a browser. No npm, no build.

Step 5 — Verify Everything Works

✅ Check Git identity and auth

git config --global user.name    # Should show your name
git config --global user.email   # Should show your email
gh auth status                   # Should show logged in as sunilmsft

✅ Test one project

Pick any project folder and verify:

cd "OneDrive\GitHub Copilot Fun Projects\swoop"
git status         # Should show clean or modified files
git log --oneline -3  # Should show recent commits
npm install        # Should complete without errors
node server.js     # Should start (Ctrl+C to stop)

✅ Test Copilot Chat

Open the SMB Dashboard folder in VS Code, then press Ctrl+Shift+I

Ask: "What is this project about?"

It should know — because it reads .github/copilot-instructions.md automatically.

✅ Test push to GitHub

cd "OneDrive\GitHub Copilot Fun Projects\Tim and Sunil building Stuff!"
echo "test" >> test.txt
git add test.txt
git commit -m "test push from personal laptop"
git push
# Then delete: git rm test.txt && git commit -m "cleanup" && git push
⚠️ git push shows stderr (exit code 1) — this is normal. The push succeeds.

All source code✅ YesOneDrive sync or git clone

node_modules❌ NoRun npm install in each project
