# Preservation Package: Hybrid Workspace / Innovation Lab

## What this package is
This documentation set preserves the intent, structure, operating model, and current state of the SMB strategy repository at a point in time.

This repository is best understood as a Hybrid Workspace / Innovation Lab:
- Workspace: shared planning, context, memory, and operational handoff.
- Innovation Lab: rapid idea evaluation, prioritization, and venture incubation.
- Product Surface: public, living artifacts hosted as static HTML dashboards.

## Primary hosted assets
- SMB Strategy Dashboard: https://sunilmsft.github.io/smb-automation/
- Project Command Center: https://sunilmsft.github.io/smb-automation/projects.html

## Core repository artifacts
- index.html: strategy lab dashboard for SMB opportunity exploration.
- projects.html: cross-project command center and precursor to a future portfolio operating system.
- context.md: strategic framing and constraints.
- memory.md: running collaboration memory and decision trail.
- SETUP-PERSONAL-LAPTOP.md and SETUP-PERSONAL-LAPTOP.html: environment and continuity setup.
- .github/copilot-instructions.md: collaboration and editing conventions for AI-assisted work.
