# 03 Project Command Center

## Role of index.html
index.html is the core SMB strategy dashboard.

It functions as:
- The canonical strategy surface for the SMB idea lab.
- A navigable synthesis of opportunity framing, idea cards, comparison logic, deep dives, GTM context, and open questions.
- The primary public artifact for communicating strategy state.

Hosted URL:
- https://sunilmsft.github.io/smb-automation/

## Role of projects.html
projects.html is a cross-project operating dashboard.

It functions as:
- A portfolio-level command center for active builds, live assets, completed projects, and references.
- A service and subscription visibility layer.
- A bridge between this strategy lab and broader venture execution across multiple repositories.

Hosted URL:
- https://sunilmsft.github.io/smb-automation/projects.html

## Strategic significance of projects.html
projects.html is the precursor to a future portfolio operating system / command center.

It already demonstrates foundational operating-system behaviors:
- Unified project inventory and status model.
- Centralized visibility into hosting, repositories, and environments.
- Operational cost and dependency awareness.
- Fast navigation between strategic planning and execution surfaces.

## Why both artifacts should be preserved together
- index.html captures strategic thesis and opportunity sequencing.
- projects.html captures execution context and portfolio orchestration.
- Together they preserve the strategy-to-execution chain.
