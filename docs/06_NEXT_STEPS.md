- Keep index.html as the SMB strategy source-of-truth.

### Phase 2: Operationalize
- Expand projects.html model into a formal portfolio operating schema.

### Phase 3: Productize the command center pattern
- Use projects.html as the blueprint for a future portfolio operating system / command center.
- Externalize data from hardcoded definitions to structured data sources when scale demands it.
- Support multiple innovation tracks under one coherent operating framework.

## Strategic guardrails
- Preserve trust-barrier sequencing in roadmap decisions.
- Preserve strategy-to-execution traceability between index.html and projects.html.
- Avoid losing historical reasoning during future refactors.

## Intended outcome
The repository remains both:
- A durable lab memory system.
- A launchpad for future ventures and operating-system-level tooling.
